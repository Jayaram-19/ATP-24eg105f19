# Week 5: Web Layouts & Introduction to React

Welcome to the **Week 5** folder! This directory contains various exercises and projects focusing on advanced CSS layouts and foundational React concepts.

## 📂 Folder Structure

- **`assignment/`**
  Contains the main assignment tasks for this week.
- **`flex1/`** & **`flexLayout/`**
  Exercises demonstrating the use of CSS Flexbox for creating responsive and flexible page layouts.
- **`react-app-1/`**
  An introductory React application showcasing basic components, state, and props.
- **`react-app-2/`**
  A follow-up React application building upon initial concepts to demonstrate more complex functionality.
- **`tables/`**
  HTML and CSS practice focused on structuring and styling tabular data.

## 🚀 Getting Started

To view the standard HTML/CSS projects (like flex layouts and tables), simply open the respective `index.html` files in your web browser. 

For the React applications:
1. Navigate into the specific app directory (e.g., `cd react-app-1`).
2. Install dependencies using `npm install`.
3. Start the development server using `npm start` (or `npm run dev` if using Vite).
