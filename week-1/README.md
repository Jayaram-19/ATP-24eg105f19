# Week 1 - JavaScript Fundamentals

This folder contains a collection of basic JavaScript programming exercises and examples covering fundamental concepts.

## Files and Concepts Covered

* **`big2.js`**: Logic for finding the largest of two numbers using conditional statements.
* **`big3.js`**: Logic for finding the largest of three numbers.
* **`bigfunc.js`**: Demonstrates the use of functions to determine the maximum numbers.
* **`employee.js`**: Working with arrays of objects. Demonstrates important array methods such as `splice()`, `findIndex()`, and `find()` to manipulate and modify employee records (adding, removing, and updating).
* **`search.js`**: Implementing basic search logic to find specific elements within an array.
* **`small.js`**: Logic to determine the smallest number among a given set of values.
* **`sum.js`**: Basic mathematical summation logic.
* **`sumOfArrayFunc.js`**: Creating a reusable function to calculate the total sum of elements within an array.

## Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

## How to Run

You can run each of these JavaScript files using Node.js from your terminal or command prompt. For example, to run the `employee.js` file, execute:

```bash
node employee.js
```
