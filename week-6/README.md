# Week 6 Assignments

This repository contains the assignments and projects for Week 6. It primarily focuses on building user interfaces and managing state with React.

## Projects Included

### 1. Adding Users (`addingusers`)
A React application demonstrating user management, handling user input, form submission, and maintaining a list of users in the state. Built with Vite and React.

### 2. Edit Counter (`editCounter`)
A React assignment focused on state management, likely involving a counter that can be modified. This directory contains the `reacttask` React project.

### 3. React App 2 (`react-app-2`)
An additional React application exploring further concepts in functional components, hooks, and the React ecosystem. Built with Vite and React.

## Setup Instructions

To run any of the React applications:
1. Navigate into the specific project directory (e.g., `cd addingusers` or `cd react-app-2`).
2. Run `npm install` to install the required dependencies.
3. Run `npm run dev` to start the development server.
